Check, version, and share
the skills your AI agents use.

SkillsOps is an open-source CLI and optional self-hosted registry for agent skills. Catch risky instructions, review changes, and install the same skill across your team’s coding tools.

A skill is a reusable set of instructions in a SKILL.md file — for tasks like code review, incident investigation, or release checklists.

$ pip install skillsops

How it works

One team checklist.
Every developer’s editor.

Your team has a code-review skill. As people copy and edit it, versions drift and changes become harder to review. SkillsOps gives you a repeatable way to check, version, and distribute each update.

01 · Write

Keep one source

Start with your existing SKILL.md or create a starter skill. Add your team’s review instructions.

skillctl create skill

02 · Check

Review before sharing

Validate the skill and scan for security findings. Add these checks to pull requests in CI.

skillctl eval audit

03 · Version

Make changes visible

Save a version locally or publish to your registry. Compare it with the previous version before rolling it out.

skillctl apply · diff

04 · Install

Use it across editors

Install the selected version into your coding tools. SkillsOps writes each editor’s instruction format.

skillctl install

What you can do

Less manual upkeep.
More confidence in each update.

Use the checks and tools you need today. Add a shared registry and repeatable review reports as your skill library grows.

Find risky instructions

Validate skill structure and scan for known security patterns before sharing. Get findings in your terminal or GitHub Actions. Static checks help review; they do not guarantee safe execution.

Access control (RBAC)

Users, four roles, and hierarchical namespaces. Scoped tokens that only narrow. Every decision lands in the audit chain. skillctl rbac assign

Policy and telemetry hooks (experimental)

Explore opt-in policy checks and OpenTelemetry integration. These libraries require your own integration; the registry and installed agent runtimes do not invoke them automatically.

Control mappings (experimental)

Preview mappings to EU AI Act, ISO 42001, and NIST AI RMF controls. Use the deterministic gap analysis to guide review; it does not certify compliance or gate a release.

Rollout modeling (experimental)

Model canary, blue-green, and staged rollout states locally in SQLite. These tools model routing and rollback; they do not control live registry or runtime traffic.

Identity and lineage utilities (experimental)

Explore local token inspection, caller-recorded lineage queries, and registry-copy helpers. Trust boundaries require integration. CI/CD starter templates are also available for review and adaptation.

Use the editors you already have

Maintain one source skill and install it into five supported editors. Choose targets explicitly, or use --target all to detect editors in your workspace.

Review changes between versions

Save named versions with content hashes. Compare instructions and manifests with skillctl diff, then install a specific version.

Make review checks repeatable

Generate a deterministic report combining security findings and schema checks with skillctl eval report. The same inputs produce the same score, without a model API call.

Back up and move your skills

Export skill versions and manifests as tar.gz or zip archives. Import them on another host for backup or migration.

Manage skills from Claude Code

Use the optional MCP plugin to validate, audit, bump versions, compare changes, and publish skills from your Claude Code conversation. Five tools connect those checks to your workflow.

For teams

Share private skills
on your infrastructure.

Your skills can contain internal processes, coding standards, and review rules. The optional registry gives your team a shared place to publish and retrieve them, with scoped access tokens and a log of registry changes.

Start on your machine

Validate, audit, store versions, and install skills locally. The core CLI needs no registry account or model API key.

pip install skillsops

Add a registry when you need one

Run the Python registry server on your own host or private cloud. Use filesystem or GitHub-backed storage, with namespace permissions and a tamper-evident audit log.

pip install "skillsops[server]" Registry setup documentation ↗

Quickstart

Try it with a local skill.

Create a starter skill, add your instructions and description, then check and install it. This example saves a local version and writes instruction files for Claude Code and Cursor. Python 3.10+ required.

~/projects/code-reviewer
# 1. Install the CLI and create a workspace
pip install skillsops
mkdir code-reviewer && cd code-reviewer
skillctl create skill my-org/code-reviewer

# 2. Write a skill with the required frontmatter
cat > SKILL.md <<'EOF'
---
name: code-reviewer
description: Review code against our team's standards. Use when reviewing a pull request.
---
# Code reviewer
Read the proposed changes. Identify correctness issues and missing tests.
Explain each finding with a file location.
EOF

# 3. In skill.yaml, set metadata.description (required), e.g.:
#   description: "Review code against our team's standards"
# Then run the checks:
skillctl validate
skillctl eval audit .

# 4. Save version 0.1.0 locally
skillctl apply --local

# 5. Write the instruction files for Claude Code and Cursor
skillctl install my-org/code-reviewer@0.1.0 --target claude,cursor

You’ll find the installed files at .claude/skills/code-reviewer/SKILL.md and .cursor/rules/code-reviewer.mdc. Choose other targets by name, or use --target all to detect editors already in your workspace.

CI audit

skillctl eval audit ./skills/ --fail-on-warning --format=github

Registry server (optional extra)

skillctl serve --hmac-key "$SKILLCTL_HMAC_KEY"

Version diff

skillctl diff my-org/x@1.2.0 my-org/x@1.3.0
